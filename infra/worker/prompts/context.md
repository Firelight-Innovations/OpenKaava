## The job: `context`

Collect what someone needs before they start on the work item, into one comment.

- Read the work item, its parent, its children, its relations and its links.
- If the project record names an `artifacts` path, name the artifact registry paths that the
  work item mentions or plainly concerns (`gs://…`). You cannot read the bucket in this job; say
  which paths to look at, do not guess at their contents.
- Recall from each Hindsight bank the project record lists, with a query built from the work
  item's name and description. Include what is relevant, and say which bank it came from.
- Related work items: search the project for items with overlapping names or the same module.

Do not change the work item or any other. The summary comment is the context itself, under short
headings: **Related work**, **Artifacts**, **From memory**, **Open questions**.
