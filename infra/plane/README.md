# Plane CE on plane-vm

The AGDP work tracker. Design, decisions and the task list: `docs/design/OPENKAAVA-PLANE-DESIGN.md`.

| Piece | Where |
|---|---|
| VM, disk, DNS, firewall, secrets, wake role | `infra/terraform/plane/` |
| Plane's release compose file, unmodified | `compose/docker-compose.v1.4.2.yaml` |
| Our one override (MinIO image) | `compose.override.yaml` |
| Settings | `plane.env.tmpl`, rendered by `render_env.py` into `/run/plane/plane.env` |
| Boot | `boot.sh`, the startup script |
| Idle stop / wake | `infra/common/kaava-idle/`, `infra/common/kaava-wake/` |

Canonical URL, from the worker and from the laptop: `http://plane.kaava.internal:8765`.

## Reaching it from Windows

Once, in an **administrator** PowerShell:

```powershell
Add-Content -Path "$env:SystemRoot\System32\drivers\etc\hosts" -Value "127.0.0.1 plane.kaava.internal"
```

Each time (plane-vm stops itself after 30 idle minutes):

```powershell
gcloud compute instances start plane-vm --zone us-central1-a --project veistra-prod
gcloud compute start-iap-tunnel plane-vm 8765 --local-host-port=localhost:8765 --zone us-central1-a --project veistra-prod
```

Leave the tunnel window open and browse to `http://plane.kaava.internal:8765`. A cold start takes
about 2 to 3 minutes before Plane answers; until then the tunnel reports connection errors.

## First-run setup (once per instance)

With the tunnel open:

```powershell
python infra\plane\first_run.py            # --profile dev for the local instance
```

It creates the instance admin (the owner), turns password login on and magic link off, creates
workspace `veistra`, signs up `agent@plane.kaava.internal` and `kaava@plane.kaava.internal` as
Members, stores one personal access token each as `plane-pat-agent` / `plane-pat-kaava`, and turns
public sign-up off. Rerunning it skips whatever is done. AI/LLM fields and SMTP stay empty
(design rule 6).

The three sign-in passwords are generated by Terraform: `plane-owner-password`,
`plane-agent-password`, `plane-kaava-password`. To sign in as yourself:
`gcloud secrets versions access latest --secret plane-owner-password --project veistra-prod`.

## Operations

- **Logs:** `gcloud compute ssh plane-vm --tunnel-through-iap -- sudo docker compose -p plane logs --tail 50`
- **Boot log:** `gcloud compute instances get-serial-port-output plane-vm | grep plane-boot`
- **Rerun boot without rebooting:** `sudo google_metadata_script_runner startup`
- **Upgrade:** snapshot `plane-data`, add the new release's compose file beside the old one, point
  `terraform/plane` and `APP_RELEASE` at it, apply, reboot. Read the release notes first.
- **Replacing kaava-worker** drops its instance-level IAM, including plane-vm's permission to wake
  it. Apply `terraform/plane` again afterwards.
