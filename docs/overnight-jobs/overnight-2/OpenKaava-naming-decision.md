# Naming Decision: HELVE-ADE → OpenKaava

> **Superseded.** OpenKaava has since been renamed **Veistra**. This file is kept
> unchanged as the record of the earlier HELVE-ADE → OpenKaava decision.

**Status:** Decided
**Old name:** HELVE-ADE
**New name:** OpenKaava
**Spelling:** K-A-A-V-A (three A's total — do not shorten to "Kava," which is a separate, trademarked consumer product category — the plant/drink)

---

## Why the rename

HELVE-ADE was built on the premise of also powering a custom game engine. That premise is gone — the product is no longer engine-adjacent, and the name no longer describes what it is.

## Why "Open"

Follows the established convention (OpenAI, OpenAPI) for open-source developer infrastructure. Signals open-source posture directly in the name.

## Why "Kaava"

`Kaava` is the Finnish word for *schema / pattern / blueprint* — real etymology, not an invented string. It was generated by translating the core brand concept ("a plan precise enough that nothing built from it can go wrong") into a language outside the commercially over-mined Romance/English naming space, which is why it cleared every collision check that words like "Spec," "Blueprint," and "Datum" failed.

**Brand truth it's built on:** *the full-scale plan is drawn once — every build after that just follows the lines.*

## What it beat

| Rejected | Reason |
|---|---|
| OpenADE | Direct name collision with an existing open-source Claude Code/Codex UI (bearlyai/openade), same category |
| OpenSpec | Already exists — YC-launched, 27k+ GitHub stars, same "spec before code" positioning |
| OpenBlueprint | IBM used this for a networking framework in the 90s; openblueprints.org also exists |
| OpenDatum | Existing company (Opendatum Inc.) |
| Tekton / Tektix / any "-ADE" acronym | The "-ADE" acronym space is fully mined: JADE (Java Agent DEvelopment Framework), SPADE (Smart Python Agent Development Environment), SCADE (Ansys, safety-critical dev environment), WADE — all real, established tools in agent/dev tooling since 2000 |
| Kava (single-a) | Real word, active trademark space (kava plant/beverage category) — different name from Kaava, not just a spelling variant |

## Screening completed

- **Domain (weak-signal DNS/RDAP check):** `openkaava.com` / `.dev` / `.io` / `.ai` and bare `kaava.dev` / `.io` / `.ai` all came back with no registered nameservers. This is a preliminary screen only — verify actual availability and price at a real registrar before purchasing.
- **Trademark (informal screen):** No exact match found for "Kaava" on Justia Trademarks or general web search. Minor unrelated background noise: a Pathfinder 2E monster tribe, a small personal Vercel project. Neither is a live commercial mark.
- **Not done yet:** a real USPTO TESS clearance search. This document is a naming screen, not legal clearance — get that before spending real branding budget (real domain purchase, logo, marketing).
